## Judge 设计(LLM-as-a-Judge)

- **系统提示**:rubric 全文注入,强制 JSON 输出(分数+理由+原文引用)
- **防偏差三件套**:
  - 位置偏差:成对比较时交换 A/B 顺序复评,不一致记平局
  - 长度偏差:提示「长度不等于质量」+超长答案人工复核
  - 宽松漂移:每 10 条插入 1 条已知基准题
- 实现见 [judge/](./judge/)
