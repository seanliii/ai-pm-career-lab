# 观点文章

> Kimi Innovation Explorer:「对下一代 AI 产品应该是什么样,有自己的答案」。观点文章=面试时「自己的答案」的来源。

## 选题方向(每个方向一篇就够,重质不重量)

1. **人机交互范式**:什么时候 Agent 该问人/自己干完/失败回退?(对应 Q2/Q15 面试题,写完=面试弹药)
2. **模型能力边界观察**:某能力从「不可用」到「可用」的临界点,产品该怎么做?(你的第一手观察)
3. **垂直领域判断**:用「任务价值×能力匹配×容错空间×数据可得」四把尺子量你的领域(对应 Q16)
4. **上下文经济学**:上下文=成本,产品功能设计的隐性约束(对应 Q5/Q13)
5. **评测观**:为什么「好 Agent」必须可量化,怎么做(对应 Q6/Q9)

## 文章模板

```markdown
# [标题:一个可辩论的观点,不是综述]

**一句话观点**:[例:下一代交互不是更自然的语言,而是更结构化的控制]

## 我的论证
[2-3 个论据,每个必须带你的第一手案例——「我用 XX 时观察到」比引用有力]

## 反方观点与我的回应
[主动写反方,证明你想过]

## 如果我是 XX 产品的 PM,我会怎么做
[落到具体产品动作,证明观点可执行]
```

## 发表渠道

知乎(中文面试官看)/ 个人公众号 / GitHub(存档+版本历史)。每篇写完在面试前重读一遍——观点会过时,「有观点」不会。
