每个原型一个子目录,README 必含四件套:**一句话需求 / demo GIF / 怎么跑起来 / 学到什么**。

## 原型模板(每个子目录 README)

```markdown
# [原型名]

**需求一句话**:[帮谁干什么]
**怎么跑**:[命令/URL]
**Demo**:[GIF]
**学到什么**:[一个具体的学习点,例:工具描述写「何时不该用」后,选错率 X%→Y%]
**失败记录**:[诚实记录,例:第一版没限 token,一个 case 烧了 ¥3]
```

## 建议选题(由浅入深)

1. **单工具 Agent**(半天):调一个 API 完成小任务——理解 function calling 基础
2. **多工具路由**(1 天):3-5 个工具,模型自选——体会工具描述质量=准确率
3. **带记忆的对话**(1 天):会话分层摘要——Context Engineering 实战
4. **长任务+断点续跑**(2 天):任务落盘、失败恢复——工程化分水岭
5. **多 Agent 协作**(2 天):先想清楚「值得拆吗」再拆——反模式意识
