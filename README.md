## 你的工作流(照这个顺序用)

```
第1步 · 摸清战场(1小时)
  打开 index.html → ① 板块逐家看 JD → ② 能力矩阵对照自己
  重点看:哪些能力你从没听过(那就是学习清单)

第2步 · 首次校准(30分钟)
  ⑩ 简历校准器 → 贴简历(或点示例感受判定标准) → 拿到 11 项三档报告
  红灯项=优先补,黄灯项=补数字和案例

第3步 · 学习补强(4-8周,按 ④ 四阶段路径)
  第1阶段:把「用过」变「拆过」(产品深度使用+拆解笔记)
  第2阶段:差异化硬技能(评测体系/MCP/上下文设计)
  第3阶段:作品集冲刺——照 06++ 项目指南做 2-3 个项目,
          模板在 portfolio-starter/,做完填数推 GitHub 置顶
  第4阶段:面试武装(16 道题+参考答案,对着练)

第4步 · 迭代校准(循环)
  改简历 → 贴校准器 → 看分 → 补 → 再贴
  校准器是词面检测(快但粗),分数满意后:
  把简历+校准报告一起发给 Claude → 人工精校+定制追问链+按强弱项出题

第5步 · 投递(按 ⑨ 分公司策略)
  同一段经历,8 家用不同侧面讲
```

## 三条最重要的提醒

1. **作品集 > 简历**(Kimi 原话)。所有学习最终要落成「可运行的东西」。
2. **每条经历要有数字**。没数字的经历在 AI PM 简历里等于没写。
3. **评测体系是最快建立的差异化**——1-2 周,启动包项目 2 有全套模板。
